# 🎮 Rian Lucas | Portfolio

Um portfólio pessoal desenvolvido com **HTML, CSS e JavaScript**, criado com uma proposta diferente dos portfólios tradicionais.

Inspirado no famoso **menu de compra do Counter-Strike 2 (CS2)**, o projeto transforma a apresentação das informações profissionais em uma experiência visual interativa, utilizando categorias, modais, timeline, certificados e projetos.

---

## 🎯 Sobre o Projeto

Este projeto foi desenvolvido para apresentar minha trajetória como **Desenvolvedor Front-End**, reunindo informações sobre minha experiência, conhecimentos, certificados, projetos e formas de contato.

A ideia principal foi fugir do formato tradicional de portfólio e criar uma interface que tivesse mais personalidade.

A estrutura visual foi inspirada no menu de compra do **CS2**, onde as categorias funcionam como diferentes partes da minha trajetória profissional.

O portfólio foi desenvolvido utilizando **HTML, CSS e JavaScript**, com foco em interatividade, organização visual e experiência do usuário.

## 🪟 Sistema de Modais

Uma das principais funcionalidades do projeto é o sistema de **modais interativos**.

Ao clicar em uma opção do menu, o JavaScript identifica qual modal deve ser aberto e adiciona a classe `active` ao elemento correspondente.

Os modais podem ser fechados de diferentes maneiras:

* ❌ Botão de fechar
* 🖱️ Clique fora do conteúdo
* ⌨️ Tecla `ESC`

Esse sistema é utilizado para apresentar informações sobre mim, experiências, tecnologias, projetos e contatos.

## 🔍 Visualização dos Certificados

Além da exibição dos certificados, o projeto possui um **visualizador de imagens**.

Ao clicar em um certificado:

1. A imagem selecionada é identificada.
2. Sua URL é atribuída ao visualizador.
3. O certificado é exibido em tamanho ampliado.
4. O usuário pode fechar a visualização pelo botão `X`.
5. Também é possível fechar clicando fora da imagem ou pressionando `ESC`.

## 📱 Responsividade

O projeto possui estilos específicos para diferentes tamanhos de tela.

### 🖥️ Desktop

A interface apresenta o menu principal ao lado da imagem do personagem.

### 💻 Tela média

Entre **701px e 1100px**, o layout passa a utilizar uma estrutura mais vertical e o menu é reorganizado em duas colunas.

### 📱 Celular

Em telas de até **700px**, o menu passa para uma única coluna, o personagem é reorganizado e os elementos da interface são redimensionados para se adaptarem ao espaço disponível.

O CSS possui media queries específicas para telas médias e dispositivos móveis.
