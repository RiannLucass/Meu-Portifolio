Sobre Mim

Olá, muito prazer! Me chamo Rian Lucas e gostaria de compartilhar um pouco sobre mim...

Sou um jovem que foi criado em Piracicaba, uma cidade do interior de São Paulo, não muito conhecida. Morando junto aos meus pais e minha irmã mais nova... Nasci no dia 26 de dezembro de 2004, onde, dezoito anos depois, comecei a me aventurar mais nesse mundo da computação e, principalmente, da programação!

E um detalhe que muita gente me pergunta é: por que eu escolhi esta área? Acontece que, desde pequeno, sempre gostei de coisas relacionadas à tecnologia, sejam elas computadores, jogos, videogames, enfim. Acredito que sou um garoto equilibrado, onde, ao mesmo tempo, gosto de me aventurar com viagens e conhecer coisas novas, ou até mesmo ficar em casa o dia todo mexendo no computador...

Portanto, escolho seguir por este caminho assim que finalizo meu ensino médio! Logo após, decido fazer um curso superior de graduação, sendo ele Análise e Desenvolvimento de Sistemas (ADS), e é aqui que tenho meu primeiro contato com a programação. Mas sou uma pessoa bem dinâmica e adoro aprender outros meios através da tecnologia, não sendo somente sobre programar, e sim sobre tudo um pouco envolvendo computação.

Algum tempo depois, decido me aprofundar em uma parte específica da programação, que seria como Desenvolvedor Front-End, tendo como base e aprofundamento linguagens como HTML, CSS, JavaScript, React e etc... Mas ainda sigo aprendendo muita coisa nova. Fiz alguns cursos online fora do ensino da faculdade, tendo como exemplo a linguagem Python!

Meu objetivo principal atualmente é continuar evoluindo como Desenvolvedor Front-End. Gostaria de transformar minhas ideias e conhecimentos em projetos reais e, principalmente, me tornar um profissional respeitado e honrado pelas pessoas que depositarem sua confiança em mim...

Sobre este projeto

Bom, esse projeto nada mais é do que o meu portfólio pessoal, criado com HTML, CSS e JavaScript! Com o objetivo de mostrar um pouco mais sobre quem eu sou, o que venho aprendendo e o que estou construindo dentro do mundo da programação.

Mas eu não queria fazer aquele portfólio tradicional, com várias seções, textos e cards espalhados pela tela. Queria fazer algo diferente, mais original e que tivesse um pouco da minha personalidade...

Como gosto bastante de um jogo que se chama CS2, tive a ideia de transformar o famoso menu de compra do jogo na estrutura do meu próprio portfólio. Assim, em vez de escolher armas, você escolhe as diferentes partes da minha trajetória, como minhas experiências, habilidades, projetos e formas de contato...

No fim, a ideia foi simplesmente sair um pouco do padrão e criar algo do meu jeito, enquanto também colocava em prática tudo aquilo que venho aprendendo durante meus estudos. Afinal, por que fazer igual a todo mundo quando dá pra criar o seu próprio menu?

Pedra, Papel ou Tesoura

Status // Concluído

Descrição

Um jogo simples de Pedra, Papel ou Tesoura desenvolvido com HTML, CSS e JavaScript. O jogador escolhe uma das três opções e enfrenta uma escolha aleatória feita pelo computador, enquanto a pontuação de ambos é atualizada durante a partida.

Tecnologias Utilizadas

HTML CSS JavaScript

Sobre o Desenvolvimento

Neste projeto, pratiquei principalmente lógica de programação utilizando JavaScript. Trabalhei com funções, condicionais, valores aleatórios e manipulação do DOM para criar a dinâmica do jogo.

A cada rodada, o computador escolhe uma opção aleatoriamente e o JavaScript verifica o resultado da partida, identificando vitória, derrota ou empate. Também implementei um sistema de pontuação que registra os pontos do jogador e do computador durante o jogo.

To-Do List

Status // Concluído

Descrição

Uma lista de tarefas desenvolvida com React, criada para praticar o gerenciamento de estados e a manipulação de listas dentro de uma aplicação. O projeto permite adicionar novas tarefas, marcar atividades como concluídas e remover itens da lista.

Tecnologias Utilizadas

HTML Styled Components JavaScript React UUID

Sobre o Desenvolvimento

Este foi um dos meus primeiros projetos utilizando React, desenvolvido com o objetivo de entender melhor como trabalhar com estados e componentes dentro de uma aplicação.

Durante o desenvolvimento, utilizei useState para controlar tanto a lista de tarefas quanto o valor digitado no campo de entrada. Também trabalhei com métodos como map() e filter() para atualizar e remover itens da lista sem alterar diretamente o estado original.

Para identificar cada tarefa individualmente, utilizei a biblioteca uuid, gerando um ID único para cada item. Também implementei a possibilidade de marcar uma tarefa como concluída, alterando seu estado diretamente na interface.

Catálogo de Filmes e Séries

Status // Em Desenvolvimento

Descrição

Uma aplicação desenvolvida em React para explorar filmes, séries e artistas, utilizando dados obtidos através de serviços externos. A aplicação apresenta conteúdos em diferentes categorias, permitindo navegar entre os filmes, acessar páginas de detalhes e visualizar trailers.

Tecnologias Utilizadas

React JavaScript Styled Components React Router

Sobre o Desenvolvimento

Neste projeto, aprofundei meus conhecimentos em React, trabalhando com componentes, estados, efeitos e navegação entre páginas. Utilizei useState para controlar os dados e estados da interface e useEffect para realizar o carregamento das informações.

Também trabalhei com o react-router-dom para criar a navegação da aplicação, permitindo acessar páginas de detalhes dos filmes através de suas respectivas identificações. Além disso, implementei componentes reutilizáveis, como botões, modal e sliders, deixando a estrutura mais organizada.

Os dados são carregados de forma assíncrona através das funções de serviço, reunindo filmes, séries e artistas em diferentes seções da página inicial.
